## Rules (黑客松規則)

> 報名即表示同意以下規則。違反行為準則者，主辦單位得請其離場並取消作品資格。

### 報名

- 報名已提前於 10/14（三）14:00 截止，名額 80 人。入選後將公布名單與 email 通知，沒入選則不另行通知。
- 可以單人組隊，每隊至少一名隊員，重複報名者將取消參與資格。
- Day 1 在 Discord 提案，不另外媒合隊友，志同道合的隊伍可自行整合。
- Day 2 現場依議題分桌或分區。同組至少一人到場，其他成員可遠端協作。
- 報名資料只用於本活動聯繫。

### 資料使用

- 可以用模擬的資料，不必真的串接 API。
- README 須註明哪些是真實開放資料、哪些是模擬資料，Demo 時口頭說明。
- 「市長，你給我聽好了」資料已去識別化，不得嘗試反推陳情人身分，也不得使用真實個資。「市長，你給我聽好了」資料僅限於此黑客松活動使用。
- 開放資料依各資料集授權使用，多數為政府資料開放授權條款。

### 作品規範

- 形式不限：App、網站、儀表板、系統原型、聊天機器人皆可，以可快速驗證的 MVP 為目標。
- Demo 時現場操作，只有簡報或設計稿不算。
- Day 1 起可開始討論與寫程式；可用開源套件與 AI 工具，須於 README 註明。
- 建議在 README 寫「如果市府上任 100 天內要落地，需要做什麼」：哪個局處、哪些資料、多少成本。
- 10/24 16:00 前透過主辦單位提供的隊伍專屬連結送出，填寫作品名稱與作品網址，可另附 GitHub 或 GitLab 程式碼網址；成員依報名資料。

### Demo 與票選

- 不設評審、不排名次，以線上票選選出前三名。
- 現場 Demo 開放 10 組（視情況增至 15 組），10/24 16:30–17:00 直播，每組約 2 分鐘，現場填單抽順序。
- 票選 10/24 16:30 開放，10/31（六）18:00 截止，在本頁投票。
- 投票須以 Google 或 LINE 登入本站，每個帳號限投一次，最多選 3 件作品；灌票或自動化投票不予計入，同票並列。
- 前三名經團隊同意，於票選截止後 7 日內刊登於沈伯洋競選官網。無獎金。

### 著作權與開源

- 著作權歸團隊所有。
- 經團隊同意，作品以開源授權（建議 MIT 或 CC BY 4.0）收錄於ㄅ級分持續迭代；不同意不影響參加與票選。

### 行為準則

- 互相尊重，不分背景、性別、年齡與政治立場，禁止騷擾、歧視與人身攻擊。
- 不得對市府或任何第三方系統做未經授權的掃描、壓測或入侵測試。
- 16:30 起直播，現場會拍照錄影。不想入鏡請在報到時領取識別貼紙。
- 本活動由沈伯洋競選辦公室主辦。參加黑客松不等於加入後援會；後援會於座談後開放自由報名。
